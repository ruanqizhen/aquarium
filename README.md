# Aquarium 🐠

免费的 3D 热带鱼屏保 / 鱼缸，网页版实时渲染。

灵感来自约 20 年前 Windows 上很火的 SereneScreen Marine Aquarium：屏保起来之后，屏幕就像一个鱼缸，里面有各种漂亮的热带鱼游来游去。

## 效果

- WebGL（Three.js）真 3D 实时渲染，不是录像循环
- 默认 18 条鱼，9 个品种：小丑鱼、蓝吊、黄吊、神仙鱼、蝴蝶鱼等，带条纹、摆尾、扇鳍、转向和鱼群避让
- 场景：珊瑚礁、海葵、海星、摇曳水草、岩石、宝箱、沙地焦散光斑、波动水面、阳光光柱、上升气泡、浮游微粒
- 慢游镜头 + 时钟，静置后界面自动变淡
- 可喂食（点水面或按钮，鱼会游来抢食）、切换夜晚模式（暖灯、鱼速放缓）、开关气泡、调节鱼的数量（8–28 条）、全屏
- 手机竖屏自动加宽视角，支持触控

## 怎么用

直接在浏览器里打开 `index.html` 就行，单文件，不用安装、不用联网、不用花钱。

也可以开 GitHub Pages：仓库 Settings → Pages → 选择 main 分支，就能得到一个在线链接，全屏打开当屏保用。

## 技术

- Three.js（本地打包进单文件）
- 纯前端，无后端、无依赖

## 来源

这是 Muse 帮我做的免费复刻版，原版 SereneScreen Marine Aquarium 是 Jim Sachs 的作品，2000 年发布，后来被微软收进 Windows XP Plus! Pack。
